## Usage Notes

### Implementation
All i18n keys use the `data-i18n` attribute in HTML:
```html
<span data-i18n="hero.title">مدیریت ناوگان</span>
```

### Language Switching
- Uses localStorage to persist language preference
- Automatically updates `dir` attribute on `<html>` element
- Updates document title based on selected language

### Direction Handling
- Persian and Arabic: `dir="rtl"`
- English: `dir="ltr"`
- CSS handles RTL/LTR layout differences automatically

### Special Characters
- Persian: Uses native Persian characters
- Arabic: Uses native Arabic characters
- English: Uses Latin characters with proper direction

### Numbers
- Persian/Arabic: Use native numerals (۰۱۲۳۴۵۶۷۸۹)
- English: Use Latin numerals (0123456789)
