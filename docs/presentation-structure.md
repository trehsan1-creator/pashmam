# AtiFarzam Presentation Structure

## Overview
This document describes the structure and content of the AtiFarzam Fleet Management System presentation website.

## Current Sections

### 1. Hero Section (`#ch-hero`)
- **Title:** مدیریت ناوگان آتی فرزام
- **Badge:** آتی فرزام
- **Description:** بستری یکپارچه، دقیق و پایدار برای موقعیت‌یابی لحظه‌ای خودروها، پایش مسیرهای حرکتی و مدیریت هوشمند ناوگان سازمانی و شخصی
- **Visual:** 3D Brushed Navy-Titanium "af" logo
- **Metrics:**
  - ۹۹.۹% پایداری ارتباط و ثبت نقطه
  - < 2m دقت مکان‌یابی ماهواره‌ای
  - 24/7 پایش پیوسته و هشدار آنی

### 2. Live Telemetry (`#ch-telemetry`)
- **Title:** دیدِ یکپارچه بر تمام نقاط مسیر
- **Description:** انتخاب هر واحد در شبکه، داده‌های موقعیت، سرعت، محدوده مجاز و وضعیت اتصال ردیاب را به نرمی همگام‌سازی می‌کند
- **Features:**
  - Interactive map with unit selection
  - Real-time coordinates, speed, distance
  - Satellite signal quality
  - Unit tabs: واحد ۱۰۴، واحد ۲۰۸، واحد ۳۱۲

### 3. Core Capabilities (`#ch-capabilities`)
- **Title:** طراحی‌شده برای نظارت دقیق و تصمیم‌گیری سریع
- **Description:** چهار ستون اصلی سامانه مدیریت ناوگان آتی‌فرزام برای کنترل کامل عملیات حمل‌ونقل و امنیت دارایی‌ها
- **Cards:**
  1. **موقعیت‌یابی** - موقعیت‌یابی لحظه‌ای و بازپخش مسیر
  2. **محدوده مجاز** - حصار جغرافیایی (Geofence)
  3. **تحلیل تردد** - گزارش‌های تحلیلی و پایش رانندگی
  4. **پایداری داده** - امنیت سخت‌افزاری و حافظه آفلاین

### 4. Hardware (`#ch-hardware`)
- **Title:** سخت‌افزار ردیاب هوشمند؛ مقاوم، دقیق و پایدار
- **Description:** ماژول‌های سخت‌افزاری آتی‌فرزام با طراحی صنعتی و قطعات استاندارد، برای کارکرد پیوسته در شرایط محیطی متنوع و ارسال بدون وقفه داده‌ها مهندسی شده‌اند
- **Blueprint Card:**
  - معماری ماژول مرکزی
  - واحد موقعیت‌یاب چندسامانه‌ای GNSS و مخابرات صنعتی
  - Specifications:
    - GPS / GLONASS: گیرنده ماهواره‌ای چندکاناله
    - 9V – 36V DC: مدار تغذیه با محافظ نوسان
    - IP65: مقاوم در برابر غبار و رطوبت
    - باتری پشتیبان: تداوم کارکرد هنگام قطع برق
- **Modular Cards:**
  1. **دقت سیگنال** - آنتن و ماژول مکان‌یابی دقیق
  2. **حافظه داخلی** - ذخیره‌سازی آفلاین در نقاط کور
  3. **درگاه‌های توسعه** - پشتیبانی از سنسورها و ورودی‌های جانبی
  4. **ایمنی مدار** - باتری داخلی و هشدار جداسازی

### 5. Software (`#ch-software`)
- **Title:** نرم‌افزار یکپارچه پایش و مدیریت هوشمند ناوگان
- **Description:** پلتفرم نرم‌افزاری آتی‌فرزام داده‌های لحظه‌ای سخت‌افزار را در قالب داشبوردهای شفاف، نقشه‌های تعاملی و گزارش‌های مدیریتی در اختیار شما قرار می‌دهد
- **Platforms Bar:**
  1. **پنل تحت وب جامع** - پایش کامل ناوگان از طریق مرورگر بدون نیاز به نصب
  2. **نسخه موبایل و واکنش‌گرا** - دسترسی سریع مدیران به موقعیت و اعلان‌ها در هر مکان
  3. **وب‌سرویس و API سازمانی** - امکان یکپارچه‌سازی مستقیم با سامانه‌های داخلی سازمان
- **Modular Cards:**
  1. **پایش زنده** - داشبورد نقشه زنده و بازپخش مسیر
  2. **گزارش‌های مدیریتی** - موتور گزارش‌ساز تحلیلی و خروجی دقیق
  3. **اعلان هوشمند** - مدیریت رویدادها، محدوده‌ها و هشدارها
  4. **مدیریت دسترسی** - تعریف کاربران و سطوح دسترسی سازمانی

### 6. GPS Benefits (`#ch-benefits`)
- **Title:** مزایا و فواید کلیدی استفاده از GPS و ردیاب هوشمند
- **Description:** استقرار سامانه ردیاب ماهواره‌ای آتی‌فرزام، علاوه بر امنیت لحظه‌ای، بهره‌وری ناوگان را افزایش داده و هزینه‌های پنهان نگهداری و پیمایش را به شکل ملموس کاهش می‌دهد
- **Benefit Cards:**
  1. **امنیت ۲۴ ساعته** - حفاظت و پیشگیری مؤثر از سرقت
  2. **صرفه‌جویی اقتصادی** - کاهش مصرف سوخت و استهلاک
  3. **چابکی عملیاتی** - مدیریت زمان و بهینه‌سازی مسیر
  4. **کاهش ریسک** - ارتقای ایمنی رانندگی و محموله
  5. **شفافیت مدیریتی** - مستندسازی خودکار و گزارش دقیق
  6. **اطمینان و هماهنگی** - تخمین دقیق زمان رسیدن (ETA)
- **Impact Strip:**
  - Motions: #10 (Klein Flip), #12 (Droplet Wave)
  - Message: بازده پایدار در مقیاس سازمانی و شخصی

### 7. Closing (`#ch-closing`)
- **Title:** دقت در هر نقطه، آرامش در مدیریت مسیر
- **Description:** یکپارچگی سخت‌افزار ردیاب خودرو (GPS) و نرم‌افزار پایش ناوگان با کاربری ساده، نرم و قابل اتکا
- **Visual:** Motion #08 (Diagonal Orbit)
- **Actions:**
  - بازگشت به ابتدای ارائه
  - مرور فواید سامانه GPS

## Design System
- **Primary Color:** #102333 (Navy)
- **Accent Color:** #f05327 (Orange)
- **Background:** #DCE1E8 (Light Gray)
- **Typography:** Peyda (Regular, SemiBold, ExtraBold)
- **Gradient:** Top-to-bottom brand navy (#102333) at 40% opacity
- **Glass Effects:** Frosted glass with backdrop-filter blur

## Loading Motions
- #08: Diagonal Orbit (رقص قطری)
- #10: Klein Flip (ورق‌خوردن چهارگانه)
- #12: Droplet Wave (موج قطره‌ای خطی)

## Scroll Rail
- Simple translucent orange-glass vertical line
- Borderless smoked gray see-through glass traveler circle
- Contour trace drawing on scroll

## Language Support
- Persian (FA) - Default
- English (EN)
- Arabic (AR)
- Top-left sliding language drawer switcher

## Responsive Breakpoints
- Desktop: Default layout
- Tablet: ~1024px
- Mobile: ~860px, ~680px
