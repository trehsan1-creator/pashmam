# آتی فرزام — وبسایت ارائه سامانه مدیریت ناوگان

ارائه تعاملی «سامانه مدیریت ناوگان آتی فرزام (GPS و ردیاب هوشمند خودرو)».
یک سایت **کاملاً استاتیک، RTL و بدون هیچ وابستگی (dependency)** با فونت پیدا،
پالت سه‌رنگ برند (`#102333` سورمه‌ای، `#f05327` نارنجی، `#DCE1E8` بکگراند)
و پشتیبانی از سه زبان فارسی / انگلیسی / عربی.

## اجرا

```bash
npm run dev      # http://0.0.0.0:3000
```

همین دستور `npm start` هم هست. سرور (`server.mjs`) یک استاتیک‑سرور ساده Node است؛
نیازی به `npm install`، باندلر یا بیلد برای اجرای محلی نیست. پورت با `PORT` قابل تغییر است.

> ⚠️ **باز کردن مستقیم `index.html` با `file://` توصیه نمی‌شود.** کروم/اج به صفحات
> `file://` یک origin تهی (`null`) میدهند و درخواست‌های CORS‑دار (اسکریپت‌های
> `type="module"`، فونت‌های `woff2`، `fetch`) را بلاک میکنند؛ نتیجهاش بکگراند
> پویا و فونت پیدا نیست. اسکریپت‌های سایت عمداً به صورت معمولی (نه ماژول ES)
> نوشته شدهاند تا بکگراند نقاط، حلقهها و تعاملات حتی با دابل‑کلیک هم کار کنند،
> اما برای **نمایش کامل و فونت پیدا** حتماً `npm run dev` و
> `http://localhost:3000` را استفاده کنید.

## ساخت خروجی قابل دیپلوی

```bash
npm run build    # کپی index.html + src/ + assets/ به dist/
```

`dist/` تولیدی است و در `.gitignore` قرار دارد (هرگز کامیت نمی‌شود).

## ساختار

```
index.html              صفحه ارائه (تمام بخش‌ها، نشان‌ها و متن‌های سه‌زبانه)
src/
  presentation.css      استایل و دیزاین سیستم
  presentation.js       تعاملات: اسکرول، شبیه‌ساز تله‌متری، نمودارها، i18n
  motions.js            موشن‌های بارگذاری برند (تولید SVG به صورت درون‌خطی)
assets/
  fonts/                فونت Peyda (۵ وزن woff2)
  images/               af-logo، typography-fa/en، isometric (۴ SVG)
scripts/build.mjs       بیلد استاتیک → dist/
server.mjs              استاتیک‑سرور محلی
netlify.toml            تنظیمات Netlify
vercel.json             تنظیمات Vercel
docs/                   مستندات مرجع محصول و سایت
```

**تک‑منبع:** سایت فقط یک نسخه دارد (`index.html` + `src/` + `assets/`).
هیچ کپی تکراری، خروجی بیلد کامیت‌شده یا فایل تک‑صفحه‌ای جداگانه در مخزن نیست.

## دیپلوی

هر دو سرویس استاتیک سرو می‌کنند و `npm run build` را اجرا میکنند:

- **Netlify:** `netlify.toml` → بیلد `npm run build`، انتشار `dist`
- **Vercel:** `vercel.json` → `@vercel/static-build` با `distDir: dist`

مرجع محتوا، رنگ‌ها، تایپوگرافی و ترجمه‌های سایت هستند.
